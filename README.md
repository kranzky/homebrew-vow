# Homebrew tap for Vow

[Vow](https://vow.kranzky.com) is an experimental programming language designed for
language models to write, with contracts proved by the Z3 SMT solver at compile time.

```
brew install kranzky/vow/vow
```

This builds `vowc` from its C seed and installs Z3 as a dependency. See the
[main repository](https://github.com/kranzky/vow) for documentation.
